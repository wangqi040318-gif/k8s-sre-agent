# 在线演示部署

**这一步还没有做。** AI大模型创新应用挑战赛需要一个公网能打开的演示地址。请部署完成后再把 URL 填进报名表。本文只写步骤，不编造已经上线的地址。

公网实例必须保持 **MOCK=1**。不要上传 kubeconfig，不要在 Cloud Secrets 里填写真实集群凭证。确认后的「执行修复」在 Mock 模式下只改该进程里的假数据。

## 推荐：Streamlit Community Cloud

代码已经可以从 `src/ui/app.py` 启动，并把仓库根目录加入 `sys.path`。根目录有 `requirements.txt`。

1. 确认 GitHub 仓库是 Public：<https://github.com/wangqi040318-gif/k8s-sre-agent> 。用你的 GitHub 账号登录 <https://share.streamlit.io> 。
2. 选择 **New app**。
   - Repository：`wangqi040318-gif/k8s-sre-agent`（若你改用 fork，选 fork）
   - Branch：`main`（文档合并进 main 之后再部署；部署功能分支评委以后会看到旧代码）
   - Main file path：`src/ui/app.py`
   - App URL：系统会给一个 `https://<名称>.streamlit.app` 。这个字符串就是报名表里的「在线演示地址」。
3. Python 版本优先 3.11。若构建日志报语法或依赖错误，在仓库增加只含 `3.11` 的 `.python-version` 后再部署。不要为了过构建去改诊断逻辑。
4. Advanced settings → Secrets **可以留空**。程序默认 `MOCK=1`，没有 `OPENAI_API_KEY` 时走规则报告，评委不需要外网模型。
   若你希望演示真实模型，只在 Cloud 的 Secrets 面板写入 Key，不要写入 Git：

   ```toml
   MOCK = "1"
   OPENAI_API_KEY = "只放在 Cloud Secrets，不要提交"
   OPENAI_BASE_URL = "https://api.openai.com/v1"
   OPENAI_MODEL = "gpt-4o-mini"
   ```

   Community Cloud 会把 Secrets 注入为环境变量。`src/config.py` 读的是环境变量。无 Key 的规则回退更稳，适合作为评委入口。
5. Deploy 完成后，用无痕窗口打开该 URL，做完下面四步再把链接写进报名表：
   - 页面出现「K8s 故障诊断 Agent」，侧栏 MOCK 为开。
   - 选择 ImagePullBackOff，点击「运行诊断」，能看到现象、证据、Runbook 和 `fix-image`。
   - 不输入 `CONFIRM` 时，「执行修复」是灰的。
   - 输入 `CONFIRM`、勾选动作、点击「执行修复」，出现「已模拟执行」。
6. 社区云空闲后会休眠。提交前自己再打开一次。评委第一次访问可能要等进程拉起，口播或 PDF 里可以提一句。

把最终 URL 填到：

- 报名表的在线演示栏
- `docs/作品简介.md` 表格里的「在线演示」（可选；若不想把 URL 再提交一次 Git，只填报名表即可）

## 其他挂法

学校机器、云主机或容器平台也可以，只要评委浏览器能访问 HTTPS 页面。在那台机器上：

```bash
git clone https://github.com/wangqi040318-gif/k8s-sre-agent.git
cd k8s-sre-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 确认 .env 里 MOCK=1，且不要配置 KUBECONFIG
MOCK=1 streamlit run src/ui/app.py --server.address 0.0.0.0 --server.port 8501
```

前面加一层 HTTPS 反代，或使用学校已经提供的公网入口。临时隧道的域名会变，报名截止前要再点开确认。安全组只开放演示端口，机器上不要放 kubeconfig。

## 报名表里贴什么

只贴评委不用登录就能打开的 HTTPS 地址，例如 `https://k8s-sre-agent.streamlit.app`（这是格式示例，不是已经存在的站点）。不要贴 localhost、内网 IP、需要校园 VPN 的地址，也不要贴仓库地址代替演示地址。仓库 URL 填在 GitHub 那一栏。

部署失败时先看构建日志：依赖是否装完、主文件路径是不是 `src/ui/app.py`、Secrets 里有没有误设 `MOCK=0`。日志里如果打印了 Key，立刻在面板里删掉并轮换密钥。
