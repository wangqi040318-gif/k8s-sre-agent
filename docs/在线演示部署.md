# 在线演示部署

**这一步还没有做。** AI大模型创新应用挑战赛需要一个公网能打开的演示地址。请部署完成后再把 URL 填进报名表。本文只写步骤，不编造已经上线的地址。

公网实例必须保持 **MOCK=1**。不要上传 kubeconfig，不要在 Cloud Secrets 里填写真实集群凭证。确认后的「执行修复」在 Mock 模式下只改该进程里的假数据。

## 推荐：Streamlit Community Cloud

仓库已经按 Community Cloud 的公开应用方式放好入口和依赖。**主文件用 `src/ui/app.py`，不要改成别的路径。** 这个文件在导入 `src` 之前把仓库根目录插入 `sys.path`，Cloud 从子目录启动脚本时也能找到包。不需要再在根目录加 `streamlit_app.py`。

请等本变更进入 `main` 后再部署。部署功能分支的话，合并之后 Cloud 仍停在旧提交，评委看到的不是最终文件。

按下面的字面值填写，不要改仓库名、分支和主文件：

| 字段 | 填写 |
|---|---|
| 平台 | <https://share.streamlit.io> |
| Repository | `wangqi040318-gif/k8s-sre-agent` |
| Branch | `main` |
| Main file path | `src/ui/app.py` |
| Python | 仓库根目录 `.python-version` 为 `3.12`，Cloud 会读到。设置里若要手选，也选 3.12 |
| Secrets | 至少 `MOCK = "1"`。模板在 `.streamlit/secrets.toml.example` |

依赖在根目录 `requirements.txt`，其中已有 `streamlit`。同文件里的 kubernetes、openai、langchain-openai、langgraph、langchain-core、python-dotenv、pyyaml、numpy 是诊断和真实集群路径要用的。在 Python 3.12 上按这个文件安装即可，不需要 `packages.txt` 或额外系统库。`pytest` 只给本地测试，装进 Cloud 环境不会改变页面。不要把 `.env`、kubeconfig 写进这个文件。

主题和无头模式在 `.streamlit/config.toml`：`server.headless = true`，关闭用量统计，浅色主题。这个文件故意不写 `server.port`、`server.address`。Cloud 自己分配端口，写死会让进程起不来。

### 操作步骤

1. 确认 <https://github.com/wangqi040318-gif/k8s-sre-agent> 仍是 Public。用能访问该仓库的 GitHub 账号登录 <https://share.streamlit.io> 。若提示安装 GitHub App，只授权这个仓库即可。
2. 选择 **Create app**（或 New app）→ **Deploy a public app from GitHub**。
3. 表单按上表填写：
   - Repository：`wangqi040318-gif/k8s-sre-agent`
   - Branch：`main`
   - Main file path：`src/ui/app.py`
   - App URL：自选子域名。保存后的地址形如 `https://<子域名>.streamlit.app`。这个地址才是报名表里的在线演示，现在还没有，不要提前编一个。
4. 展开 **Advanced settings**。Python 保持 3.12。在 Secrets 粘贴：

   ```toml
   MOCK = "1"
   ```

   这与 `.streamlit/secrets.toml.example` 的必填项相同。Streamlit 在跑脚本之前解析 Secrets，并把字符串写进环境变量；`src/config.py` 读的就是环境变量。不粘贴也可以，因为代码默认 `MOCK=1`。粘贴是为了让面板上能看见演示被锁在 Mock。
5. 评委演示不要取消注释模型密钥。若你自己要看模型报告，只在 Secrets 面板追加下面三行，不要写入 Git，也不要写成空字符串：

   ```toml
   OPENAI_API_KEY = "替换成你的密钥"
   OPENAI_BASE_URL = "https://api.openai.com/v1"
   OPENAI_MODEL = "gpt-4o-mini"
   ```

   本地调试把 `.streamlit/secrets.toml.example` 复制为 `.streamlit/secrets.toml` 再改。后者已被 `.gitignore` 排除。
6. 点击 **Deploy**。构建日志应出现从 `requirements.txt` 安装，然后启动 `src/ui/app.py`。完成后用无痕窗口打开 App URL，做完这四步再写入报名表：
   - 页面标题是「K8s 故障诊断 Agent」，说明里 MOCK 为开。
   - 选择 ImagePullBackOff，点击「运行诊断」，能看到现象、证据、Runbook 和 `fix-image`。侧栏里还有 Pending、ConfigMap 挂载失败、探针未就绪、Service 无 Endpoints，确认词同样是 `CONFIRM`。
   - 不输入 `CONFIRM` 时，「执行修复」是灰的。
   - 输入 `CONFIRM`、勾选动作、点击「执行修复」，出现「已模拟执行」。
7. 社区云空闲后会休眠。提交前自己再打开一次。评委第一次访问要等进程拉起，口播或 PDF 里可以提一句。

Secrets 里不要出现 `MOCK = "0"`、`KUBECONFIG` 或证书。公网进程上的确认执行只会改该进程里的假数据；一旦关掉 Mock，同一按钮会尝试改真实集群。

把最终 URL 填到：

- 报名表的在线演示栏
- `docs/作品简介.md` 表格里的「在线演示」（可选；若不想把 URL 再提交一次 Git，只填报名表即可）

## 其他挂法

学校机器、云主机或容器平台也可以，只要评委浏览器能访问 HTTPS 页面。在那台机器上：

```bash
git clone https://github.com/wangqi040318-gif/k8s-sre-agent.git
cd k8s-sre-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# 确认 .env 里 MOCK=1，且不要配置 KUBECONFIG
MOCK=1 streamlit run src/ui/app.py --server.address 0.0.0.0 --server.port 8501
```

前面加一层 HTTPS 反代，或使用学校已经提供的公网入口。临时隧道的域名会变，报名截止前要再点开确认。安全组只开放演示端口，机器上不要放 kubeconfig。

## 报名表里贴什么

只贴评委不用登录就能打开的 HTTPS 地址，例如 `https://k8s-sre-agent.streamlit.app`（这是格式示例，不是已经存在的站点）。不要贴 localhost、内网 IP、需要校园 VPN 的地址，也不要贴仓库地址代替演示地址。仓库 URL 填在 GitHub 那一栏。

部署失败时先看构建日志，对照这几项：依赖是否从根目录 `requirements.txt` 装完、Main file path 是不是 `src/ui/app.py`、分支是不是 `main`、Secrets 里有没有 `MOCK = "0"`。日志里如果打印了 Key，立刻在面板里删掉并轮换密钥。
